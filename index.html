02 / NOTA DEL EDITORPULSO WEB · UNIDAD III

EDITORIAL

Detrás de cada
pantalla hay
una estructura.

Cuando abro una página web suelo fijarme primero en cómo se ve: los colores, la distribución o la facilidad con la que encuentro lo que busco. Sin embargo, detrás de esa apariencia existe una estructura que hace posible cada elemento.

En esta revista decidí presentar los conceptos de HTML y CSS desde una perspectiva práctica: qué función cumple cada etiqueta, cómo se aplica un estilo y por qué el posicionamiento influye en la experiencia del usuario.

Mi intención es explicar estos recursos con ejemplos sencillos y mostrar cómo pueden combinarse para diseñar interfaces ordenadas, legibles y adaptables.

04 / INTRODUCCIÓNHTML · CSS · JAVASCRIPT

01 — PUNTO DE PARTIDA

Una página web
tiene tres capas.

HTMLEstructura / contenido<h1><p><section>
CSSAspecto / distribucióncolorgridfont
JSLógica / respuestaevents()fetch()

HTML define qué elementos existen y cuál es su significado: títulos, párrafos, enlaces, listas y secciones.

CSS controla cómo se presentan esos elementos: colores, tipografía, márgenes, tamaño, posiciones y adaptación a distintas pantallas.

JavaScript agrega comportamiento. En el navegador responde a eventos; en el servidor puede procesar solicitudes y enviar datos mediante HTTP.

IDEA CLAVE

La estructura y el diseño se complementan, pero cumplen responsabilidades distintas. Separarlos facilita mantener un proyecto.

05 / DESARROLLOCAPÍTULO 01 · CSS

HOJAS DE ESTILO

El lenguaje que
define la identidad visual.

Una hoja de estilo reúne reglas CSS que el navegador aplica a un documento HTML. Puede estar en un archivo externo, dentro de una etiqueta <style> o en un atributo style. Para esta revista elegí un archivo externo porque permite mantener el contenido separado del diseño.

index.html
<head>
  <link rel="stylesheet"
        href="estilos.css">
</head>
01 · Reutilización

Una regla puede transformar muchos componentes a la vez.

02 · Consistencia

Las variables permiten mantener colores y tamaños.

03 · Adaptación

Las media queries ajustan el diseño a cada pantalla.

ASÍ FUNCIONA EL MODELO DE CAJA

MARGIN
BORDER
PADDING
CONTENT

Cada elemento ocupa espacio según su contenido, el relleno (padding), el borde (border) y el margen (margin).

La cascada

Cuando varias reglas compiten, intervienen el origen, la importancia, las capas, la especificidad y el orden de aparición.

06 / DESARROLLOCAPÍTULO 02 · REGLAS

SELECTORES + LISTAS DE DECLARACIONES

Primero se selecciona.
Luego se define el estilo.

Un selector identifica los elementos HTML que recibirán una regla. Dentro de las llaves se escribe una lista de declaraciones; cada declaración combina propiedad y valor, separados por dos puntos y terminados con punto y coma.

estilos.css
.tarjeta {         /* selector */
  color: #fff;
  background: #111;
  padding: 24px;
}
SelectorPropiedadValor

TRES FORMAS DE SELECCIONAR

pEtiquetaTodos los párrafos0–0–1
.destacadoClaseElementos con esa clase0–1–0
#principalIDElemento con ese identificador1–0–0

La especificidad compara los pesos de los selectores cuando las declaraciones compiten en la misma condición de cascada. Un ID tiene más peso que una clase; una clase, más que una etiqueta.

07 / DESARROLLOCAPÍTULO 03 · HTML5

ESTRUCTURA SEMÁNTICA

Etiquetas que
dan sentido al contenido.

<section>

Una parte con un tema propio

Agrupa un bloque temático del documento. Normalmente incluye un encabezado que permite identificar de qué trata esa sección.

<hgroup>

Un título y su texto asociado

Reúne un único encabezado de nivel h1 a h6 y uno o más párrafos para un subtítulo o frase complementaria.

¿Para qué sirve?

La semántica facilita entender la estructura, mantener el HTML y comunicar mejor las partes del documento a tecnologías de asistencia.

fragmento-semántico.html
<section aria-labelledby="titulo-css">
  <hgroup>
    <h2 id="titulo-css">
      Hojas de estilo
    </h2>
    <p>Diseño para la web</p>
  </hgroup>
  <p>Introducción al CSS.</p>
</section>

POSICIONAMIENTO DE ELEMENTOS WEB

No basta con existir.
Hay que saber dónde estar.

LIENZO / POSICIONES
static Flujo normal
relative Se desplaza, conserva espacio
absoluteRespecto al contenedor
fixed Se fija a la ventana
sticky

Representación conceptual de las cinco modalidades de position.

static

Posición inicial en el flujo; los desplazamientos no se aplican.

relative

Permite mover visualmente un elemento sin perder su espacio original.

absolute

Se ubica respecto al ancestro posicionado más cercano y sale del flujo normal.

fixed

Permanece anclado a la ventana de visualización, salvo casos especiales.

sticky

Se adhiere durante el desplazamiento cuando alcanza un umbral definido.

Y para organizar columnas…

display: flex y display: grid resuelven distribuciones completas sin depender de posiciones absolutas.

DE LA INTERFAZ A LOS DATOS

El navegador pregunta.
El servidor responde.

Además de HTML y CSS, una aplicación puede usar JavaScript en el servidor con Node.js. El navegador realiza una petición HTTP y el backend devuelve una respuesta, por ejemplo, en formato JSON. Esta revista puede leerse como sitio estático; el proyecto también incluye un servidor de demostración opcional.

CONCLUSIONES

Diseñar también
es organizar.

Durante la elaboración de esta revista comprendí que HTML y CSS no se limitan a «hacer bonita» una página. Las etiquetas aportan significado, los selectores permiten trabajar con precisión y el posicionamiento ayuda a ordenar la información.

Considero que la mejor solución combina una estructura clara, estilos reutilizables y una presentación que facilite la lectura. JavaScript complementa ese trabajo cuando es necesario agregar interacción o conectar servicios.

Una página bien construida se entiende y se utiliza con facilidad.
